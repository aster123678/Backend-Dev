# Middleware Practice Exercises

This folder contains simple Express and Mongoose examples for the middleware exercises shown in the screenshot.

## Install

```bash
npm install
```

## Run

```bash
npm run exercise1
npm run exercise2
npm run exercise3
npm run exercise4
npm run exercise5
```

Exercises 3 and 4 need MongoDB running locally on `mongodb://127.0.0.1:27017`.
